# Generic face detector

`face.xml` is OpenCV's `haarcascade_frontalface_default.xml`, distributed with opencv-python-headless 4.13.0.92. The license and original attribution are embedded in the XML and must be retained.

Source: https://github.com/opencv/opencv/blob/4.13.0/data/haarcascades/haarcascade_frontalface_default.xml

This generic pretrained detector locates a face. It does not identify a person, compare identities, test liveness, or certify a photograph. It was not trained on citizens' cards.
