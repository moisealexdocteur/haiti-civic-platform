# Haiti Civic Platform

Plateforme modulaire, multi-tenant et marque blanche destinée à la gestion
d'adhésions volontaires, à la participation civique, aux opérations terrain
et aux processus de conformité électorale.

## Principes techniques

- PHP
- CodeIgniter 4
- MariaDB
- Docker
- Progressive Web App
- API REST versionnée
- Architecture modulaire
- Multi-tenant
- Français / Kreyòl ayisyen
- Optimisée pour faibles débits et anciens appareils

## Environnements

- Development
- Staging
- Production

## Sécurité

Le dépôt ne doit jamais contenir :

- mots de passe
- clés API
- tokens GitHub
- données NINU
- documents d'identité
- données personnelles réelles
- fichiers `.env` de production

Toutes les données de développement doivent être fictives.
